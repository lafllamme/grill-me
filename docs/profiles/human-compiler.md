# Human Compiler

## Kategorie

Positiv · Clarity

## Scoring

- Clarity: `≥85`
- Safety: `≥60`
- Workflow: `≥60`
- Complexity: `≥65`
- Context: `≥65`

## Profil

Der Code ist so klar benannt und strukturiert, dass Menschen ihn fast so direkt
verarbeiten können wie ein Compiler.

## Erwartete Evidence

- aussagekräftige Variablen- und Funktionsnamen
- kleine, nachvollziehbare Kontrollflüsse
- wenig lokale Überraschungen oder versteckte Seiteneffekte

## Roast-Richtung

Respektvoll übertreiben: Der Code erklärt sich schneller als die
Dokumentation.

## Konstruktives Feedback

Die Klarheit beibehalten und prüfen, ob sie auch über Modul- und
Repository-Grenzen hinweg erhalten bleibt.

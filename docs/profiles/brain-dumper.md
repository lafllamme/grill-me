# Brain Dumper

## Kategorie

Negativ · Clarity

## Scoring

- Clarity: `≤35`
- Safety, Workflow, Complexity und Context: jeweils `≥55`

## Profil

Gedanken werden direkt in Code gekippt. Es gibt Teile, aber kaum erkennbare
Ordnung, Benennung oder Struktur, die andere sicher weiterführen können.

## Erwartete Evidence

- uneinheitliche Namen und Zuständigkeiten
- verschachtelte oder zufällig zusammengesetzte Kontrollflüsse
- fehlende gemeinsame Struktur für ähnliche Probleme

## Roast-Richtung

Nicht Spaghetti — eher der komplette Kühlschrankinhalt auf einmal in den Topf.

## Konstruktives Feedback

Zuerst Zuständigkeiten und wiederkehrende Begriffe sortieren, bevor weitere
Features auf die bestehende Struktur gesetzt werden.

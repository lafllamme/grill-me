# Careful Squasher

## Kategorie

Gemischt · Workflow

## Scoring

- Clarity: `≥70`
- Safety: `≥70`
- Workflow: `40–60`
- Complexity: `≥60`
- Context: `≥70`

## Profil

Der Code ist grundsätzlich ordentlich, aber Arbeitsstände werden zu stark
gebündelt oder die Entwicklung dazwischen bleibt schwer nachvollziehbar.

## Erwartete Evidence

- wenige ungewöhnlich große Commits
- mehrere fachlich unabhängige Änderungen in einem Commit
- Commit-Messages, die den Umfang nicht ausreichend erklären

## Roast-Richtung

Gute Zutaten, aber alles landet in einem einzigen Commit-Topf.

## Konstruktives Feedback

Änderungen entlang fachlicher oder reviewbarer Einheiten trennen und Messages
konkreter auf den Grund der Änderung ausrichten.

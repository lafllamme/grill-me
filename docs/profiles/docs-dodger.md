# Docs Dodger

## Kategorie

Gemischt · Context

## Scoring

- Clarity: `≥65`
- Safety: `≥65`
- Workflow: `≥65`
- Complexity: `≥65`
- Context: `≤50`

## Profil

Der Entwickler kann grundsätzlich sauber arbeiten, hinterlässt aber zu wenig
Informationen, damit andere die Absicht und den nächsten sicheren Schritt
verstehen.

## Erwartete Evidence

- fehlende README- oder Modul-Erklärungen
- wichtige Entscheidungen ohne Kontext
- Kommentare und Commit-Messages erklären eher das Was als das Warum

## Roast-Richtung

Der Code ist da. Die Gebrauchsanweisung offenbar auf dem Rückweg.

## Konstruktives Feedback

Nur die entscheidenden Absichten, Grenzen und Betriebsannahmen dokumentieren,
statt pauschal mehr Text zu produzieren.

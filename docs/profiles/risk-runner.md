# Risk Runner

## Kategorie

Gemischt · Safety

## Scoring

- Clarity: `≥65`
- Safety: `40–60`
- Workflow: `≥65`
- Complexity: `≥65`
- Context: `≥65`

## Profil

Arbeitet insgesamt gut, geht bei Eingaben, Fehlerpfaden oder kritischen
Grenzen aber zu hohe Risiken ein und verlässt sich zu stark auf den normalen
Ablauf.

## Erwartete Evidence

- unvollständige Validierung
- wenige Tests für ungültige oder fehlende Zustände
- Fehler werden weitergereicht, ohne sinnvoll eingeordnet zu werden

## Roast-Richtung

Der Code läuft schnell — direkt auf der schmalen Kante.

## Konstruktives Feedback

Die riskantesten Daten- und Vertrauensgrenzen identifizieren und dort zuerst
explizite Checks und Tests ergänzen.

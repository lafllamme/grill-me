# Edge-Case Sheriff

## Kategorie

Positiv · Safety

## Scoring

- Clarity: `≥65`
- Safety: `≥85`
- Workflow: `≥60`
- Complexity: `≥60`
- Context: `≥60`

## Profil

Behandelt Validierung, Fehlerpfade und Sonderfälle nicht als lästige Ausnahme,
sondern als Teil des eigentlichen Features.

## Erwartete Evidence

- robuste Eingabevalidierung
- explizites Error Handling
- Tests an kritischen Grenzen und bei ungültigen Zuständen

## Roast-Richtung

Der einzige Entwickler, der einen Fehlerfall findet, bevor der Fehler ihn
findet.

## Konstruktives Feedback

Die Schutzlogik dort konzentrieren, wo sie Risiken reduziert, statt sie über
alle Ebenen zu duplizieren.

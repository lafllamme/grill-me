# Git Gardener

## Kategorie

Positiv · Workflow

## Scoring

- Clarity: `≥70`
- Safety: `≥60`
- Workflow: `≥85`
- Complexity: `≥60`
- Context: `≥60`

## Profil

Pflegt kleine, nachvollziehbare Arbeitspakete und hält die Entwicklung auch
über viele Commits hinweg lesbar.

## Erwartete Evidence

- sinnvolle Commit-Größen
- konkrete Commit-Messages
- nachvollziehbare Reihenfolge von Änderungen

## Roast-Richtung

Jeder Commit sieht aus, als hätte er vorher kurz durchatmen dürfen.

## Konstruktives Feedback

Die gute Granularität mit aussagekräftiger Kontext-Evidence in größeren
Refactorings absichern.
